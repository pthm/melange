# {{ site.Title }}

> {{ site.Params.description }}

Melange is an OpenFGA-to-PostgreSQL compiler. You write an OpenFGA (.fga) authorization model and a `melange_tuples` SQL view over your existing tables; `melange migrate` compiles the model into PostgreSQL functions such as `check_permission`, called from SQL or the Go and TypeScript clients.
